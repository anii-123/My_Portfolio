## 🌐 Live Portfolio

> **🔗 [https://my-portfolio-anii-123.vercel.app](https://my-portfolio-anii-123.vercel.app)**

A modern, fully responsive **Developer Portfolio Web Application** built with **React 19**, **Vite 8**, **Tailwind CSS v4**, and **Framer Motion** — deployed on **Vercel** with auto-deploy on every push to `main`.

---

## ✨ Features

| Feature | Description |
|---|---|
| 🎯 **Hero Section** | Animated typing headline, real-time stat metrics, CTA buttons |
| 📂 **Projects Showcase** | Category filter tabs with 6 featured case studies |
| 🔍 **Case Study Modal** | Problem → Solution → Architecture → Metrics deep-dives |
| 🧠 **Skills Matrix** | Categorized proficiency bars with icon badges |
| 🕐 **Timeline** | Milestone education & achievement roadmap |
| 🏅 **Certificates** | Verified credentials from Deloitte, TATA, Udemy & more |
| 📬 **Contact Section** | Form with validation + copy-to-clipboard email |
| ⌨️ **Command Palette** | `Ctrl+K` / `Cmd+K` spotlight search & navigation |
| 🌑 **Dark Glassmorphism UI** | Premium dark theme with glow accents & micro-animations |

## 🚀 Run Locally

```bash
# 1. Clone the repository
git clone https://github.com/anii-123/My_Portfolio.git
cd My_Portfolio

# 2. Install dependencies
npm install

# 3. Start development server (http://localhost:5173)
npm run dev

# 4. Build for production
npm run build
```
