# Anisha Prakash Gurumukhi - Developer Portfolio

A modern, responsive, state-of-the-art **Developer Portfolio Web Application** built with **React 18**, **Vite**, **Tailwind CSS (v4)**, and **Framer Motion**.

---

## 🌟 Key Features

- **Interactive Hero Section**: Animated typing headline, real-time stat metrics, and CTA buttons.
- **Featured Projects & Case Studies**: Category filter tabs showcasing **EcoPack-AI**, **FarmConnect**, **Amazon Prime Video PowerBI Analytics**, **Productivity-WFH**, **LeetCode DSA**, and **Prodexa App**.
- **Interactive Case Study Modal**: Problem statement, solution details, metrics, and architecture stack.
- **Skills Matrix**: Categorized technical proficiency matrix with progress bars and icon badges.
- **Timeline & Verified Credentials**: Milestone roadmap & certificates from Deloitte, TATA, Udemy, and Alpha Batch.
- **Interactive Contact Section**: Contact form with validation and copy-to-clipboard email utility.
- **Command Palette (`Ctrl + K` / `Cmd + K`)**: Quick spotlight search and navigation modal.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS + Glassmorphism
- **Icons**: Lucide React + React Icons
- **Deployment**: Vercel / Netlify

---

## 🏃 Run Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build production bundle
npm run build
```
